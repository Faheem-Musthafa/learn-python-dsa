# Stepwise: learn Python, data structures and algorithms

A free course for total beginners, with every explanation written so a 10-year-old can follow it.

- 28 modules, from "what is code?" to dynamic programming and a maze-solver project
- Step-by-step moving pictures you control, with guess-first questions
- Real Python running in your browser (Pyodide), with friendly error messages
- Practice questions with hints and full answers, and spaced review
- A personal progress tracker that stays on your device: no account, no server

Open `index.html` through any static web server. Run it locally with `python -m http.server`.

## For contributors

- `docs/AUTHORING.md` explains the lesson format
- `node tools/check.mjs --pyodide` runs every Python program in the course in the browser runtime and checks the content
- `docs/research/` holds the research behind the design
